# NEON BREAKER

یک بازی آرکید بریک‌اوت نئونی، سریع و «آبدار» — بدون هیچ وابستگی، تصویر یا فایل صوتی. همه‌چیز با Canvas 2D و Web Audio به‌صورت زنده ساخته می‌شود.

## دموی زنده

**https://fakee516.github.io/neon-breaker/**

## اجرا

کافی است `index.html` را باز کنید. همین.

اگر ترجیح می‌دهید با سرور محلی اجرا شود:

```bash
python -m http.server 8080
# سپس http://localhost:8080
```

صدا به دلیل محدودیت مرورگرها فقط بعد از اولین کلیک یا فشردن کلید فعال می‌شود.

## کنترل

| کار | دسکتاپ | موبایل |
|---|---|---|
| حرکت پدال | ماوس / `A` `D` / کلیدهای جهت | کشیدن انگشت |
| پرتاب توپ | `Space` | ضربه (Tap) |
| توقف | `P` یا `Esc` | دکمه `II` |
| صدا | `M` | دکمه `M` |
| شروع مجدد | بعد از باخت `Space` یا `R` | ضربه |

## چرخه بازی

- ۳ جان؛ مراحل بی‌نهایت با ۸ الگوی هندسی (دیوار، شطرنجی، الماس، موج، قلعه، فلش، قلب، حلقه) که به‌ترتیب تکرار می‌شوند.
- سرعت توپ با هر مرحله بیشتر می‌شود و سختی با آجرهای زره‌پوش و بمب‌ها بالا می‌رود.
- **آجر معمولی:** یک ضربه. **زره‌پوش:** ۲ تا ۳ ضربه. **بمب:** با انفجار زنجیره‌ای همسایه‌ها را پاک می‌کند.
- **کمبو:** هر ۵ آجر بدون برگشت به پدال، ضریب امتیاز را بالا می‌برد (تا ×۸). برگشت به پدال کمبو را صفر می‌کند.
- **پاورآپ‌ها:** MULTI BALL، WIDE PADDLE، LASER، STICKY، SLOW MOTION و +1 LIFE.
- بهترین رکورد در `localStorage` نگه داشته می‌شود و پایان هر دست، آمار کامل (مرحله، آجرها، پاورآپ‌ها) نمایش داده می‌شود.

## حس بازی

- رد نور توپ، ذرات، حلقه انفجار، لرزش دوربین، فلاش رنگی و متن‌های شناور.
- نوار پیشرفت مرحله، شمارنده کمبو، نشانگر زمان پاورآپ‌ها و هشدار ضربان قرمز در آخرین جان.
- موسیقی و همه افکت‌ها به‌صورت procedural با اسیلاتورها و نویز ساخته می‌شوند؛ هیچ asset خارجی وجود ندارد.
- رابط لمسی اختصاصی: دکمه‌های Pause/Mute، راهنمای Tap to Serve و راهنمای چرخش دستگاه در حالت عمودی.

## ساختار

```
neon-breaker/
├─ index.html
├─ style.css
├─ favicon.svg
├─ js/
│  ├─ core.js      قوانین خالص: تولید مرحله، هندسه، امتیاز، پاورآپ‌ها
│  ├─ audio.js     سینت صدا و موسیقی
│  └─ game.js      فیزیک، رندر، ورودی، وضعیت بازی
└─ tests/
   └─ core.test.js  تست‌های Node
```

## تست

```bash
npm test
# یا
node tests/core.test.js
```

۱۲ گروه تست بدون وابستگی اجرا می‌شوند: قطعی‌بودن تولید مرحله، قرارگیری آجرها داخل زمین، الگوها، سرعت، برخورد دایره/مستطیل، بازتاب، کمبو، امتیازدهی، پاورآپ‌ها و سازگاری ثابت‌ها.

بازی علاوه بر آن در Chrome با تست خودکار مرورگر بررسی شده است: شروع، برخورد و امتیاز، توقف/ادامه، پاک‌سازی مرحله، پاورآپ‌ها، انفجار زنجیره‌ای، باخت، رکورد، ری‌استارت، حالت لمسی و نبود خطای کنسول.

## جزئیات فنی

- فیزیک با گام ثابت ۱۲۰ هرتز و رندر مستقل با `requestAnimationFrame`.
- مقیاس‌پذیری رندر تا DPR ۲ و نسبت ثابت ۳:۲.
- بدون شبکه، بدون فونت یا تصویر خارجی؛ از `file://` هم اجرا می‌شود.
- کلیدهای ذخیره‌سازی: `neonbreaker.best` و `neonbreaker.muted`.
