# NEON BREAKER

یک بازی آرکید بریک‌اوت نئونی، سریع و «آبدار» — بدون هیچ وابستگی، تصویر یا فایل صوتی. همه‌چیز با Canvas 2D و Web Audio به‌صورت زنده ساخته می‌شود.

## دموی زنده

**https://fakee516.github.io/neon-breaker/**

## اجرا

کافی است `index.html` را باز کنید. همین.

اگر ترجیح می‌دهید با سرور محلی اجرا شود:

```bash
python -m http.server 8080
# سپس http://localhost:8080
```

صدا به دلیل محدودیت مرورگرها فقط بعد از اولین کلیک یا فشردن کلید فعال می‌شود.

## کنترل

| کار | دسکتاپ | موبایل |
|---|---|---|
| حرکت پدال | ماوس / `A` `D` / کلیدهای جهت | کشیدن انگشت |
| پرتاب توپ | `Space` | ضربه (Tap) |
| توقف | `P` یا `Esc` | دکمه `II` |
| صدا | `M` | دکمه `M` |
| شروع مجدد | بعد از باخت `Space` یا `R` | ضربه |

## چرخه بازی

- ۳ جان؛ مراحل بی‌نهایت با ۸ الگوی هندسی (دیوار، شطرنجی، الماس، موج، قلعه، فلش، قلب، حلقه) که به‌ترتیب تکرار می‌شوند.
- سرعت توپ با هر مرحله بیشتر می‌شود و سختی با آجرهای زره‌پوش و بمب‌ها بالا می‌رود.
- **آجر معمولی:** یک ضربه. **زره‌پوش:** ۲ تا ۳ ضربه. **بمب:** با انفجار زنجیره‌ای همسایه‌ها را پاک می‌کند.
- **کمبو:** هر ۵ آجر بدون برگشت به پدال، ضریب امتیاز را بالا می‌برد (تا ×۸). برگشت به پدال کمبو را صفر می‌کند.
- **پاورآپ‌ها:** MULTI BALL، WIDE PADDLE، LASER، STICKY، SLOW MOTION و +1 LIFE.
- بهترین رکورد در `localStorage` نگه داشته می‌شود و پایان هر دست، آمار کامل (مرحله، آجرها، پاورآپ‌ها) نمایش داده می‌شود.

## حس بازی

- پس‌زمینه‌ی نئونی زنده با گرید، سه هاله‌ی نورانی متحرک، ستاره‌های چشمک‌زن و وینیت؛ پس‌زمینه در CSS کامپوزیت می‌شود تا بار رندر کم بماند.
- آجرهای شیشه‌ای با گرادیان، لبه‌ی نورانی، درخشش، ترک و نشانگر جان برای آجرهای زره‌پوش و هسته‌ی تپنده برای بمب‌ها.
- توپ با هاله و دنباله‌ی نور، پدال شیشه‌ای با پالس انرژی، خم‌شدن کوتاه هنگام ضربه و توپ‌های چندگانه.
- تکه‌های شکسته‌شده (debris)، ذرات نرم additive، حلقه‌ی انفجار، لرزش دوربین، فلاش رنگی و متن‌های شناور.
- HUD شیشه‌ای با پنل‌های Score/Level/Power-ups/Lives، نوار پیشرفت مرحله، چیپ‌های زمان پاورآپ و نشان کمبو با شمارنده.
- منوی بازطراحی‌شده با تیتر گرادیانی و درخشش متحرک، چیپ‌های ویژگی، دکمه‌ی نورانی و ذرات شناور.
- هر مرحله رنگ تأکیدی خودش را دارد و در پس‌زمینه، HUD و بنر مرحله دیده می‌شود.
- موسیقی و همه افکت‌ها به‌صورت procedural با اسیلاتورها و نویز ساخته می‌شوند؛ هیچ asset خارجی وجود ندارد.
- رابط لمسی اختصاصی: دکمه‌های Pause/Mute، راهنمای Tap to Serve و راهنمای چرخش دستگاه در حالت عمودی.

## تست

```bash
npm test
# یا
node tests/core.test.js
```

۱۲ گروه تست بدون وابستگی اجرا می‌شوند: قطعی‌بودن تولید مرحله، قرارگیری آجرها داخل زمین، الگوها، سرعت، برخورد دایره/مستطیل، بازتاب، کمبو، امتیازدهی، پاورآپ‌ها و سازگاری ثابت‌ها.

بازی علاوه بر آن در Chrome با تست خودکار مرورگر بررسی شده است: شروع، برخورد و امتیاز، توقف/ادامه، پاک‌سازی مرحله، پاورآپ‌ها، انفجار زنجیره‌ای، باخت، رکورد، ری‌استارت، حالت لمسی و نبود خطای کنسول.

## جزئیات فنی

- فیزیک با گام ثابت ۱۲۰ هرتز و رندر مستقل با `requestAnimationFrame`.
- رندر با نسبت ثابت ۳:۲؛ DPR تا ۲ با سقف حدود ۳ مگاپیکسل برای حفظ فریک‌ریت روی نمایشگرهای پرتراکم.
- پس‌زمینه‌ی ثابت (گرید، هاله‌ها و وینیت) با CSS کامپوزیت می‌شود و canvas شفاف فقط عناصر متحرک را می‌کشد.
- بدون شبکه، بدون فونت یا تصویر خارجی؛ از `file://` هم اجرا می‌شود.
- کلیدهای ذخیره‌سازی: `neonbreaker.best` و `neonbreaker.muted`.

## بهینه‌سازی

- آجرها، توپ، پدال، پاورآپ‌ها و ذرات به‌صورت sprite از پیش رندرشده کشیده می‌شوند؛ هیچ گرادیان یا سایه‌ی جدیدی در هر فریم برای این عناصر ساخته نمی‌شود.
- پس‌زمینه‌ی ثابت از canvas خارج و به CSS منتقل شده؛ blend-modeهای سنگین حذف شده‌اند تا روی سیستم‌های ضعیف هم روان بماند.
- شمارنده‌ی آجرهای زنده جای اسکن کل آجرها را گرفته، تعداد ذرات/خرده‌ها سقف دارد و دنباله‌ی توپ در حالت چندتوپی کوتاه‌تر می‌شود.
- هنگام Pause رندر متوقف می‌شود و فقط یک فریم از صفحه‌ی توقف کشیده می‌شود.
- در تست خودکار با رندر نرم‌افزاری headless و DPR ۲، صحنه‌ی بازی با ~۳ مگاپیکسل ۶۰ فریم را نگه داشت و استرس مرحله ۱۴ هم ۶۰ فریم ماند.

## تغییرات نسخه ۱.۱

- بازطراحی کامل گرافیک: آجرهای شیشه‌ای، HUD پنلی، منوی سینمایی، پس‌زمینه‌ی CSS و افکت‌های جدید.
- خرده‌های برخورد، خم‌شدن پدال، امتیاز نرم و رنگ تأکیدی مرحله.
- بهینه‌سازی جدی رندر؛ حذف blend-modeها، spriteهای کش‌شده، پس‌زمینه‌ی CSS و توقف رندر در Pause.
